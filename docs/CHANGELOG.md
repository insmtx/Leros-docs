# Changelog

## [v0.8.0] - 2026-06-10

### AI 队友工作台焕新

官网与工作台叙事全面升级，AI 队友的能力和适用场景更清楚了。

- 新增靛蓝与黑灰两套官网主题
- 更新岗位与行业解决方案展示
- 优化任务执行流程和版本沉淀说明

## [v0.7.2] - 2026-05-28

### 文档修改更顺手

生成文档后，可以围绕选中内容继续修改，并保留每次调整的版本。

- 支持 Word 文档查看与局部修改
- 新增文档版本记录
- 优化长文档生成稳定性

## [v0.7.0] - 2026-05-12

### 知识库和 Skill 正式见面

AI 队友可以检索组织知识，并调用沉淀好的 Skill 完成高频任务。

- 上线组织知识库检索
- 支持创建和复用 Skill
- 新增任务执行过程展示

## [v0.6.0] - 2026-04-20

### 第一批 AI 队友到岗

资料研究、方案撰写和会议纪要等常见角色可以直接创建使用。

- 上线资料研究员与方案撰写员
- 上线会议纪要助手
- 支持会话生成文件
